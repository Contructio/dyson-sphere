#### 📜 Эффект перка
You are not just familiar with modern devices. You've designed a lot of them. You can roll an engineering check to remember a bypass integrated in an object or a system that can give you an edge with that object. An example of that would be remembering a locks springs have enough space to push all the pins above the sheer line, so there is no need to fight all those security pins, thus dropping Security DC from 25 to 10.
